# Draftly Context

Context policies that guide every Draftly agent. These files are injected into
agent system prompts and enforced by evaluation.

## Files

- **project_context.md** — what Draftly is and how it works
- **architecture.md** — system architecture and key components
- **documentation_policy.md** — rules for all documentation work
- **writing_style.md** — voice, structure, and style for generated content
- **repository_rules.md** — how Draftly works inside a repository
- **security_rules.md** — mandatory security constraints
- **evaluation_rules.md** — how output is scored and when it fails
- **human_review_policy.md** — when and how humans review output
- **support_policy.md** — how support questions are handled
- **diagram_rules.md** — rules for diagrams in documentation

Each policy is small and actionable so agents can apply it directly.
