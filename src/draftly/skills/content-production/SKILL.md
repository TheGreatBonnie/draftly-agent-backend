# Content production

- Use only claims supported by the supplied evidence.
- Preserve source feedback IDs and feedback-gap IDs in output metadata.
- Mark unknown information as unknown instead of inventing details.
- Produce drafts only; never publish, schedule, or call delivery APIs.
- Keep X output at or below 280 characters.
- Include evidence references in every generated output.
