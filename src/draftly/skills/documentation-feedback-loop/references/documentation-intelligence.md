# Documentation Feedback Loop — Documentation Intelligence

## Purpose
Model for aggregating feedback loop outputs into actionable documentation intelligence. Provides dashboards, trends, and strategic insights.

## Intelligence Layers
### Layer 1: Operational (Real-time)
- **Open gaps count** by priority
- **Doc runs in flight** with gap linkage
- **Recent closures** (last 7 days)
- **SLA compliance**: % gaps closed within priority SLA

### Layer 2: Tactical (Weekly)
- **Top gap topics** by frequency × severity
- **Platform distribution** of signals
- **Category trends**: `how_to` vs `docs_gap` vs `complaint`
- **Time-to-close**: Median days from detection to closure
- **Reopen rate**: % gaps reopening within 30 days

### Layer 3: Strategic (Monthly/Quarterly)
- **Coverage growth**: New pages created vs gaps closed
- **Staleness reduction**: % pages fresh per `freshness-rules.md`
- **Support deflection**: Questions answered by docs vs human
- **Contribution hotspots**: Code areas generating most gaps
- **ROI**: Doc effort (PRs) vs support volume reduction

## Key Metrics
| Metric | Formula | Target |
|--------|---------|--------|
| Gap Detection Rate | gaps detected / week | Stable or decreasing |
| Gap Closure Rate | gaps closed / gaps opened | ≥ 1.0 |
| Median Time to Close | median(days_open) | ≤ 7 days (High), ≤ 30 (Medium) |
| Reopen Rate | gaps reopened / gaps closed | ≤ 10% |
| Coverage Ratio | documented topics / total topics | ≥ 80% |
| Staleness Ratio | stale pages / total pages | ≤ 20% |
| Support Deflection | doc-linked answers / total answers | ≥ 60% |

## Intelligence Artifacts
### Gap Report (per `documentation-gap-report.md` asset)
- Executive summary
- Top 10 gaps with evidence
- Trend charts (weekly)
- Recommended actions

### Coverage Map
- Topic → documentation status (covered/partial/missing)
- Topic → gap history (detection count, last detected)
- Topic → code ownership (for accountability)

### Support-Doc Correlation
- Question cluster → doc page mapping
- Doc update → question volume change (pre/post)
- Unanswered questions → gap candidates

## Trend Analysis
### Leading Indicators
- Rising `how_to` clusters → upcoming feature adoption
- Rising `complaint` + `how_to` → usability issues
- New topic clusters → undocumented features

### Lagging Indicators
- Closure rate → team capacity/process health
- Reopen rate → documentation quality
- Staleness → maintenance debt

## Actionable Insights
| Pattern | Insight | Action |
|---------|---------|--------|
| Cluster in new feature area | Feature shipped without docs | Prioritize `documentation-generation` |
| Recurring `complaint` on existing page | Page unclear/incomplete | Prioritize `documentation-update` |
| High reopen rate | Fixes not addressing root cause | Deep-dive review, rewrite |
| Staleness clustering in module | Module ownership gap | Assign doc owner |
| Low deflection on high-traffic topic | Docs exist but not discoverable | Improve IA, search, linking |

## Data Sources
- `GapDetector` clusters (topic, size, severity, platforms)
- `GapPrioritizer` scores (priority, ranking)
- `documentation_audit.py` freshness/staleness
- `documentation-evaluation` scores
- Git history (doc PRs, code changes)
- Support message volume (by channel/topic)

## Integration
Generated by scheduled `run_feedback_loop()` + `run_documentation_audit()`.
Consumed by:
- Human review dashboard
- Sprint planning (gap backlog)
- Documentation roadmap
- Team health metrics
